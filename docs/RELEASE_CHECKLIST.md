# 发布检查清单

## 自动检查

- [ ] `npm run verify` 或 `pnpm run verify` 全部通过。
- [ ] `bilibili-office-reader.user.js` 与发布用 `.txt` 内容一致。
- [ ] 元信息中的版本号已递增。
- [ ] `CHANGELOG.md` 已更新。
- [ ] 仓库中没有 Cookie、令牌、个人动态内容或调试日志。

## 真实浏览器回归

- [ ] 从将要公开的地址全新安装脚本。
- [ ] 旧版本覆盖升级后分组和设置仍然存在。
- [ ] 三种内容筛选和作者分组筛选正常。
- [ ] 长文可以展开和收起，阅读位置合理。
- [ ] 评论抽屉可以打开、再次点击收起、继续加载和失败重试。
- [ ] 评论抽屉关闭后再次打开可恢复滚动位置。
- [ ] 空闲刷新不会打断长文、评论或设置操作。
- [ ] 设置导出、合并导入、替换导入和撤销正常。
- [ ] 登录失效或接口异常时有明确提示。
- [ ] 窄窗口和浏览器 200% 缩放下仍可操作。

## GitHub

- [ ] 创建 `vX.Y.Z` 标签。
- [ ] 使用 `CHANGELOG.md` 内容撰写 GitHub Release。
- [ ] Release 附加 `.user.js`，需要时附加同内容 `.txt`。
- [ ] Release 页面中的安装文件可正常下载和安装。

## Greasy Fork

- [ ] 提交完整、未压缩、可阅读的用户脚本。
- [ ] 名称、描述和语言标记正确。
- [ ] 版本号高于 Greasy Fork 上一版本。
- [ ] GitHub 项目主页和 Issue 地址可访问。
- [ ] 从 Greasy Fork 安装后完成一次冒烟测试。
- [ ] 验证下一次补丁版本能够自动更新。
