# Greasy Fork 发布文案

## 简介

将 B 站动态转换为低干扰的纯文字阅读界面，隐藏封面、图片和复杂 UI，专注阅读关注 UP 主发布的文字内容。支持内容筛选、作者分组、长文展开、纯文字评论、空闲刷新、分组提醒及配置备份。

## 主要功能

- 纯文字动态列表，自动去重并过滤空动态、直播通知和无法查看的充电专属动态。
- 全部动态、排除视频、纯文字三种筛选方式。
- 手动给 UP 主分组，并按分组筛选或设置新动态提醒。
- 长文展开与收起。
- 右侧纯文字评论抽屉，支持继续加载、失败重试和阅读位置恢复。
- 无操作一段时间后自动刷新；正在阅读或设置时暂缓刷新。
- 字号、行距、通知、正文预览和配置备份设置。

## 安装与升级

安装后登录 B 站并打开 <https://t.bilibili.com/>。从旧版本升级时请直接覆盖安装，不要先删除旧脚本，以免用户脚本管理器清除本地分组和设置。

## 隐私

脚本不包含广告、统计、遥测或第三方追踪。分组和阅读设置保存在用户脚本管理器本地；评论只向 Bilibili 官方接口请求。请勿向维护者发送密码或 Cookie。

## 已知限制

功能依赖 B 站页面结构和接口。登录失效、内容权限限制、风控或网站更新可能导致部分动态和评论无法加载。评论区仅用于文字阅读，不提供发送、点赞或完整楼中楼交互。
